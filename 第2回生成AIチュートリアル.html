今回のZoom純正文字起こしは、残念ながら後半約30分だけ残っていました。前半約78分は文字起こしが残っていないため、このページでは次のように分けて整理しています。

  • 後半の内容：Zoom純正文字起こしに残っている発言をもとに整理

  • 前半で確認した可能性がある宿題：次回、必要なら口頭で拾い直す

重要 このページは、比呂美さん・Ikumiさんがあとで読み返して、**「次に自分は何をすればいいか」**が分かるための復習ノートです。技術の細かい裏側ではなく、実際に使う場面を中心に書いています。

今日の結論：手で頑張る前に、AIに一度やらせる

今回の合言葉は、これです。

人に聞く前に、まずAIに聞く。
AIでうまくいかなかったところだけ、長田に聞く。

これは「自分で何とかしなさい」という意味ではありません。むしろ逆です。

今までなら、分からないことがあるたびに、検索したり、人に聞いたり、手で直したりしていました。これからは、その前にAIへ一度投げます。

  • ファイルが見つからない
  • ChatGPTの返事が長すぎる
  • Wixの更新を自動化したい
  • TimeTreeと予定管理をつなげたい
  • LINEやメールの文章を整えたい

こういうものを、まずAIに相談する。AIの答えが足りなければ、そこから長田に聞く。この順番にすると、毎回の困りごとがそのままAI活用の練習になります。

1. 比呂美さんの今日の前進

今回いちばん大きかったのは、比呂美さんが自分でChatGPTに聞き、その答えを読みながら、さらに聞き方を調整していたことです。

最初の質問では、ChatGPTは「パソコン上のファイルは直接探せません」と答えました。そこで終わらずに、長田と一緒に聞き方を変えました。

その結果、次の違いが見えてきました。

使い方 できること 注意点
ブラウザ版ChatGPT（Safariなど） 添付したファイル、Google Drive、Gmailなどは扱える Macの中を直接探すのは苦手
デスクトップアプリ版ChatGPT 許可した範囲なら、Mac内のファイル探しに使える可能性がある 最初にフォルダへのアクセス許可が必要になる

つまり、ポイントは「ChatGPTはできる／できない」ではなく、どの画面で、どの範囲を見せているかです。

2. ファイル探しは、こう聞く

比呂美さんの大きな課題の一つは、Macの中のファイルが増えすぎて、必要な資料を探すのに時間がかかることです。

次回までに試すなら、まずは一つだけで十分です。

例：ChatGPTへの依頼文
Macの中から「後援名義申請」に関するWord・PDFを探して。
2025年以降のものを一覧にして。
ファイル名、場所、内容の要約を短く出して。

うまくいかないときは、質問を変えます。

  • 「ブラウザ版ではなく、デスクトップアプリでやる必要がありますか？」
  • 「どのフォルダを許可すれば探せますか？」
  • 「まずファイル名だけで探す方法を教えてください」
  • 「画面に収まるくらい短く、3つだけで答えてください」

ヒント ChatGPTの返事が長すぎるときは、遠慮なく「短く」と言って大丈夫です。
例：「画面に収まる長さで、箇条書き3つにして」

3. Typeless：話すだけで、整った文章にする

今回、後半で強く印象に残ったのが Typeless でした。

通常の音声入力は、話した言葉をそのまま文字にします。言い直しや「あのー」「えーと」も入りやすいです。

Typelessは少し違います。

  1. 話す
  2. AIが一度考える
  3. 言い淀みを整えた文章として出す

だから、LINE・メール・ChatGPTへの指示文づくりに向いています。

4. Typelessの使い方メモ

iPhoneでの基本手順

  1. App Storeで Typeless を入れる
  2. iPhoneの設定で、キーボードにTypelessを追加する
  3. 必要に応じて「フルアクセスを許可」をオンにする
  4. LINEなどの入力画面を開く
  5. キーボード左下の地球儀マークを長押しする
  6. Typelessを選ぶ
  7. マイクを押して話す
  8. もう一度押して止める
  9. AIが整えた文章を確認して、送信する

使いどころ

  • LINEの返事
  • メールの下書き
  • ChatGPTへの相談文
  • Wix更新の説明文
  • NPOの案内文・依頼文のたたき台

メモ 文章が出たあと、手で細かく直しすぎなくて大丈夫です。直したいところがあれば、次はAIに「もっと短く」「やわらかく」「事務局らしく」と頼む練習にできます。

5. Ikumiさんの強み：先に動かしてみる力

今回からIkumiさんも参加しました。

Ikumiさんは、普段から音声入力を使っていて、新しいアプリもその場で入れて試すスピードがありました。比呂美さんは慎重に確認しながら進むタイプです。

この組み合わせは、AI活用ではかなり良い形です。

  • 比呂美さん：目的、活動の意味、判断基準を持っている
  • Ikumiさん：まず動かして試す、設定を進める力がある
  • AI：下書き、整理、検索、文章化を担当する
  • 長田：詰まったところを一緒にほどく

目指す形は、姉妹で全部を手作業することではありません。人が決めることと、AIに任せることを分けることです。

6. WixとTimeTreeは、次回こう進める

Wix

Ikumiさん側のサイトはWixで運用されています。Wixは、今後AIとつなげて更新作業を軽くできる可能性があります。

ただし、最初に必要なのは技術設定ではありません。

次回までに、Ikumiさんには次のような形で考えておいてもらうと進めやすいです。

Wixで、毎回どこを更新していますか？

例：

  • お知らせを追加する
  • イベント情報を直す
  • 写真を差し替える
  • 文章を少し書き換える
  • 日程や参加方法を更新する

まず「毎回やっている更新」を3つ出します。そこがAI化の入口です。

TimeTree

比呂美さんは、すでにChatGPTにTimeTree連携を2回ほど相談し、最終的には「できません」という答えを受け取っていました。

ここは少し上級コースなので、今回は長田が持ち帰っています。

比呂美さん側で今やることは、技術の調査ではありません。次回までに、予定管理で最近困った場面を一つ思い出しておくことです。

例：

  • 予定がLINEで来て、カレンダーに入れ忘れた
  • 変更が来て、どれが最新か分からなくなった
  • 誰と共有した予定か分からなくなった
  • TimeTree、Googleカレンダー、紙のメモが混ざった

この「困った具体例」が分かると、TimeTreeを使い続けるのか、別のカレンダーに寄せるのか、AIにどこを任せるのかを判断できます。

7. パスワード・アカウントで止まるのは普通

今回、アプリを入れる途中で、ログインやパスワード確認に時間がかかる場面がありました。

これは比呂美さんだけの問題ではありません。新しいAIツールを増やすと、ほとんどの人がここで止まります。

次回以降、必要なら一度だけ、次の整理をすると楽になります。

  • どのメールアドレスでログインしているか
  • Apple / Google / ChatGPT / Wix / TimeTree のどれを使っているか
  • iPhoneとMacで同じアカウントを使っているか
  • パスワードをどこで安全に管理しているか

注意 NPO関係の情報、写真、関係者の連絡先、ログイン情報は慎重に扱います。分からないままAIに全部入れるのではなく、必要な範囲だけを確認して使います。

9. 次回に確認すること

次回は、機能の説明からではなく、実際に困った出来事から入ります。

予定管理

  1. 最近、日程調整で困った出来事は何ですか？
  2. その予定はどこから来ましたか？（LINE／メール／電話／口頭など）
  3. どの段階が一番面倒でしたか？
  4. 最終的にどこへ記録しましたか？
  5. 誰と共有する予定でしたか？

ファイル管理

  1. 最近、必要なファイルが見つからず困った場面は何ですか？
  2. 何の資料を探していましたか？
  3. どの言葉で検索しましたか？
  4. 最後は見つかりましたか？
  5. 見つかった場合、どこにありましたか？

ここが分かると、AIに何を任せるべきかがはっきりします。
